# 작업 완료 체크리스트

## 코드 변경 후 확인 사항

### 1. 기본 확인
- [ ] 문법 오류 없는지 확인 (브라우저 콘솔)
- [ ] import/export 경로 정확한지 확인
- [ ] 함수명, 변수명 오타 없는지 확인

### 2. 기능 테스트
- [ ] 로컬 서버 실행 후 브라우저에서 테스트
- [ ] 각 검사 흐름이 정상 작동하는지 확인
- [ ] localStorage 데이터 저장/로드 정상 확인

### 3. UI 확인
- [ ] 반응형 레이아웃 확인 (모바일/데스크톱)
- [ ] 스타일이 깨지지 않는지 확인

### 4. 커밋 전
- [ ] 불필요한 console.log 제거
- [ ] 주석 정리
- [ ] git add 및 commit

## 빌드/배포
- 별도 빌드 과정 없음 (정적 파일)
- 파일을 웹서버에 직접 업로드하면 배포 완료
